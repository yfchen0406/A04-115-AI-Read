# 日本新潟秋季深度自由行

這是可直接雙擊查閱、也可上傳至靜態網站的前端網站包。網站以 147 鏡分鏡表時間碼為畫面唯一依據，Remotion 負責旁白、字幕、場景與索引同步。

## 開啟網站

雙擊 index.html 進入無封面首頁，再按「開始旅遊行程」開啟播放器。首頁、旅遊行程、詳細行程與費用整理均為靜態 HTML，不需伺服器或後端。請保留目前資料夾結構與相對路徑。

## 上傳網站

將本資料夾內所有檔案上傳到網站同一目錄。首頁是 index.html，播放器是 reading.html；網站僅使用 HTML、CSS、JavaScript、JSON、WebP 與 MP3。

## 旁白、字幕與分鏡

- 旁白：audio/narration.mp3，使用新潟發音修正版。
- 時長：1,872.78 秒。
- 時間軸：147 鏡、440 段字幕、10 個章節。
- 畫面：images/scene-001.webp 至 images/scene-147.webp。
- 播放器、時間滑桿和章節索引使用相同時間軸；章節跳轉對齊至該章第一鏡。
- data/sync-validation.json 記錄音檔雜湊、時長、鏡數及字幕首尾時間。

## 其他分頁

「詳細行程」位於 itinerary.html，「費用整理」位於 costs.html。兩頁保留原有圖文排版與可點擊放大的資訊圖表；YT 連結仍待補上網址。
