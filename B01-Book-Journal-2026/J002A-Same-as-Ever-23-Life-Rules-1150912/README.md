# 《一如既往》23條生活守則網頁｜四種圖片版本版

## 新增功能
1. 首頁右側圖片切換按鈕改為四種：
   - 資訊圖表
   - 意象圖表
   - 簡單意象
   - 手繪插畫
2. 每一條法則圖片下方，也可單獨切換四種版本。
3. 點上方按鈕：全頁 23 張圖片同步切換。
4. 點單張圖片下方按鈕：只切換該張圖片，不影響其他張。

## 圖片放置規則
- `website/assets/images/infographic/` → 資訊圖表
- `website/assets/images/concept/` → 意象圖表
- `website/assets/images/simple-concept/` → 簡單意象
- `website/assets/images/handdrawn/` → 手繪插畫

四個資料夾中的命名都相同：
- `law-01.webp`
- `law-02.webp`
- ...
- `law-23.webp`

## 封面
- `website/assets/images/cover-hero.webp`
