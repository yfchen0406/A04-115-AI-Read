# 東坡・心境群島

以蘇軾詩詞為內容的本機靜態網頁，不需要安裝套件或連線即可閱讀。

## 開啟方式

在檔案總管中雙擊 `index.html`，即可用瀏覽器開啟。

## 目前內容

- 15 首蘇軾詩詞與簡短的「島上慢想」導讀
- 可拖曳旋轉、上下調整角度、滾輪縮放的 3D 群島地圖
- 八角分層浮島、木板棧橋，以及依各首詩詞意境配置的景物
- 主題篩選、關鍵字搜尋、隨機漫遊、月夜配色、播放／暫停《但願人長久》和每日東坡籤
- 探訪進度儲存在目前瀏覽器的本機儲存空間

所有樣式、3D 繪製與互動程式都在 `index.html` 內，不需外部函式庫、安裝或網路連線；作品介紹及導讀是本原型整理的閱讀文案。

本機音檔放在 `assets/music/dan-yuan-ren-chang-jiu.mp3`，由播放按鈕開始播放；網站不會自動播放。

## 3D 操作

- 滑鼠按住地圖拖曳：旋轉群島並調整俯視角度
- 滑鼠滾輪：放大或縮小
- 點島嶼或上方標籤：閱讀該首詩詞
- 手機或平板：在地圖上拖曳旋轉，點選島嶼開啟作品
- 「全景」按鈕：回復初始角度與大小
