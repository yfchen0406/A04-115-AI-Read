## 專案現況

- 網站為單頁 `index.html`，包含序章、康熙、雍正、乾隆、經濟資料庫、中西比較、三帝比較、歷史時間軸、知識測驗及來源等章節。
- 樣式與部分互動程式內嵌於 HTML；第一階段另有 `css/qing-animations.css` 與 `js/qing-animations.js`。
- 經濟區原有六指標 SVG 圖、資料列、年份滑桿與播放、國家選擇、來源連結和限制說明。`economic_data.json` 包含 78 筆觀測與 9 筆來源。
- 第一階段的 GSAP/ScrollTrigger 動畫開關及原有頁面互動均需保留。

## 六項資料現況

| 指標 | 現有資料 | 重要限制 |
|---|---|---|
| 人口 | 1776 十三殖民地估計、1790 美國普查兩點 | 地理範圍與統計方法不同，不連線、不排名 |
| 人均 GDP | 中國、英國、法國、荷蘭、西班牙、北美/美國多族群估計；1700/1750/1800 | 1990 國際元的歷史重建錨點，不是逐年統計；1800 超出乾隆在位 |
| 城市化 | 英國、法國、荷蘭、西班牙、俄羅斯；1700/1750/1800 | Bairoch ≥5,000 人城市估計區間中點；清朝缺同口徑資料 |
| 財政 | 清朝與五個歐洲國家；1725/1775 兩點 | 50 年區間平均的人均中央收入，繪圖年份只是區間中心 |
| 貿易專題 | 四旗國類別、四個 25 年區間 | 指標是被強迫自非洲登船的人數估計，不是商品貿易額；零值保留為資料值 |
| 工業化代理 | 英國留存生棉進口量；兩個來源時段 | 僅為紡織原料需求代理，兩時段來源口徑不同，不是工業產值或跨國排名 |

## 衝突與保護

新版以獨立 CSS/JavaScript 和新增區塊實作，不改既有經濟 SVG、核心資料 JSON、原有年度與國家互動程式、圖片或其他章節。圖表採實際觀測年份顯示，稀疏錨點不補值。通用時間控制器只移動游標；不能把範圍外或不同定義的數值宣稱為可比較。

## 驗收狀態

- 已檢查原始 JSON 為合法 JSON、觀測筆數 78，且與修改前備份的 SHA-256 相同。
- 已用 Node.js 語法檢查新增 JavaScript；CSS、HTML 引用與中繼 JSON 的路徑存在。
- 目前環境沒有 Playwright 瀏覽器自動化套件，亦未完成實際 Chrome/Edge、Android/iPhone 觸控、圖表點擊與播放的人工作業驗收。應在部署前以 Netlify 預覽或本機 HTTP 伺服器完成互動檢視。
- CDN 及 `fetch` 需網路與 HTTP(S) 頁面；直接以 `file://` 開啟新增 JSON 資料圖表不受支援。CDN/JSON 失敗時原本 SVG 圖表仍保留。

## 第二階段擴充後的互動範圍

- 國家篩選固定列出七個目標地區；缺乏指標列者停用並標示原因，圖上只加入該指標真實存在的資料系列。指標內的地理單位例外（如Dutch Republic、旗國、美國）維持逐列原名。
- 年份控制器與原站 `worldYear` 雙向同步；另外提供跳至年份、重播起點、1/2/4年每步、時期按鈕與事件標記/清單。
- 折線、共同錨點長條排名及兩國比較均由來源資料與中繼資料決定是否可用。各指標的排名只限同來源、同單位、同時點；人口與工業代理禁排。人均GDP另保留 Cambridge 1990 國際元版本，MPD 2023列為待匯入獨立版本。
- 財政額外12筆總額估計存於 sidecar，不回寫原始JSON。一般國際商品進出口金額尚未匯入；SlaveVoyages資料固定稱為強迫登船人數專題。
- `node js/economic-data-validator.js` 從原始JSON及擴充sidecar重建正規化列與品質報告；如要復現檢查，須確保原始JSON、來源登錄、中繼資料及擴充檔均在部署副本中。
- 最終資料品質快照：78筆原始觀測、82筆擴充觀測（財政與人口）、160筆正規化觀測；0重複鍵、0其他錯誤，11筆1800年資料超出目標期間並保留於來源但不呈現在1661–1799游標範圍。
- 免外掛 smoke test 會實際呼叫控制器並檢查年份裁切、共享年份、事件、排名、比較、財政總額、跳轉與播放/暫停；它是模擬 DOM/ECharts 的狀態測試，不能替代瀏覽器畫面或觸控驗收。
- 回歸查核發現兩國模式的圖表系列原先仍受多國勾選篩選影響，可能摘要有差距而圖上少線。已改為按兩國下拉選項獨立組線，並加入取消地區勾選後兩條線仍顯示的 smoke assertion。
- 增加西班牙加勒比貿易改革（1765）、阿姆斯特丹信貸危機（1772）及巴達維亞共和國（1795）事件；事件詳情附 Cambridge 學術章節、Economic History Review 論文或 Rijksmuseum 來源連結，並測試事件連結及非因果提示。
- 2026-10-31補查 Clio Infra Total Population 官方中繼：主要序列使用現代國界回溯、1500–1800每50年，另有 England 歷史疆界系列。Compact workbook 在可用研究工具回應 HTTP 403，故只登記為候選，未匯入或宣稱完成人口七區覆蓋。
- 補查 OWID 洲際貿易人均圖表：其指標是1700年價格英鎊的殖民/洲際貿易代理，並非完整進出口總額，地區覆蓋不含清朝、俄羅斯或美洲殖民地。CSV 端點在可用研究工具不可存取，故列入來源候選，未擷取數值。
- OWID/HYDE 人口候選研究後續已透過官方指標 API 核對並匯入獨立 sidecar（詳見成果報告增補）；本盤點保留研究當時的候選狀態紀錄，最終可用範圍以該增補、來源登錄與品質報告為準。
