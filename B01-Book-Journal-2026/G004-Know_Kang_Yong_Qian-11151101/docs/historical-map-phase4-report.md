- 補齊驗收清單明列的 1763 年《巴黎和約》、1787 年美國憲法簽署、1789 年新憲法政府開始依法運作三筆事件，並加入 1763、1787 年快速跳轉。1789 年事件說明法律生效、國會實際組織與總統就職是不同日期；三筆事件連結美國國家檔案館或國務院史料。
- 經區域座標檢核修正四條歐洲軍事示意線經緯度順序，並加入歐洲戰區及跨洲公司航線起點的地理範圍測試。
- 地圖模式保留原有年表及經濟資料庫的選取同步。現有經濟資料與主要頁面內容未被移除。
- 地圖區新增桌機拖曳／滾輪及手機雙指拖曳／捏合操作提示，並說明單指滑動用於頁面捲動；自動化檢查會確認這些觸控提示保留於頁面。
- 貿易路線卡直接列出主要港口、組織及商品；軍事行動卡直接列出主要地區、交戰方與結果，兩者均連到逐筆資料來源。
- 地圖或 GeoJSON 載入失敗時，錯誤提示提供直達共用歷史事件年表的連結，讓使用者仍可查閱事件與原始來源。
- 增加資料來源索引、地點信心註記及事件 GeoJSON 建置腳本。
- 新增 Cliopatria v0.2.1（CC BY 4.0）衍生政體圖層 `data/maps/historical-polities.geojson`，共 579 個依來源有效年代篩選的多邊形。含清朝、所列歐洲政體，以及部分美洲殖民帝國／政體與豪德諾索尼聯盟；每筆附低信度、來源、原始年份及限制。來源資料用 `FromYear`／`ToYear` 區間選取，沒有插值或重畫幾何。ZIP 不包含 46 MB 上游壓縮檔；可用 `scripts/compile-historical-polities.py` 及其 SHA-256 固定版本重建。來源覆蓋檢視未找到蘇格蘭多邊形，英格蘭／大不列顛年份亦有間隔，故已列入畫面與方法報告的缺口。
- 政體多邊形改為非阻塞載入；若大型政體資料未能讀取，地圖仍載入事件與路線，並在資料狀態中單獨提示失敗。世界、清朝、歐洲與美洲模式皆有自動測試，核對圖層、年份篩選、文字清單與點擊來源詳情。

- 真實頁面檢查發現並修正兩項整合問題：經濟圖表年代捷徑容器缺少其事件委派選擇器；MapLibre 尚在非同步載入時開啟雙地圖會過早呼叫地圖建構器。修正後，捷徑可正常綁定，雙地圖會等函式庫完成載入再建立。

## 資料範圍與限制

地圖底圖使用 OpenFreeMap Liberty 樣式。它呈現現代地理底圖，不代表 18 世紀政治疆界。另提供低信度的 Cliopatria 來源政體範圍參考圖層；清朝地理覆蓋不完整，歐洲及美洲政體名單有限，美洲圖形不等同十三殖民地或完整原住民族領域。不可將這些來源範圍當成精確國界或法律主權。事件座標是用於地圖定位的代表位置；低信心座標只表示區域定位。貿易及軍事線均為概略示意，不代表量測後的實際航線、控制線或行軍路徑。

奴隸販運路線獨立成圖層，與一般商業貿易分開呈現。使用者可在來源索引中查閱資料出處、授權與解讀限制。底圖及地圖函式庫透過 CDN 載入；公開底圖服務以現況提供，需有網路連線。若底圖無法載入，頁面仍保留文字事件及路線清單。

## 本機使用

解壓後以支援靜態檔案的本機 HTTP 伺服器開啟資料夾根目錄的 `index.html`。地圖及資料檔需要透過 HTTP 載入；直接以 `file://` 開啟時，瀏覽器可能封鎖資料請求或 ES module。部署時可將 ZIP 內網站根目錄內容直接部署至任何靜態網站主機。

在自己的網站根目錄或子目錄執行的步驟與外部 CDN／底圖需求，另見 `static-site-run.md`。本工作未推送程式碼至 GitHub，也未上傳到網站代管平台。

## 使用者畫面問題追查（2026-11-01）

使用者提供的截圖明確顯示第三階段「歷史事件資料載入失敗，請以 HTTP 網頁方式開啟」，第四階段地圖也顯示 GeoJSON／底圖未載入提示。這表示頁面以 `file://` 開啟或其同源資料請求未成功；瀏覽器因此封鎖 JSON／GeoJSON，第三階段事件年表無法填入，地圖初始化也在載入資料階段中止。截圖沒有顯示瀏覽器網址列，故不能單憑截圖斷言實際協定；頁面錯誤訊息已指出 HTTP 是必要條件。

已增補：
- `index.html` 在偵測到 `file://` 時顯示本機 HTTP 開啟提示。
- 歷史年表與地圖的錯誤區塊會辨別 `file://` 與 HTTP(S) 情境，分別提示啟動本機伺服器或檢查資料路徑、CDN、底圖及 CSP。
- 第三階段提供與統一年份及國家篩選同步的互動地圖預覽；第四階段保留完整六圖層控制、雙地圖比較及全螢幕操作。兩個畫布共用同一資料與時間控制器。
- 新增 `start-local-site.cmd`，使用 Windows 已安裝的 Python 3 啟動本機靜態 HTTP 網站；不需部署或後端程式。網站仍需要網路連線載入 MapLibre、GSAP、ECharts 及底圖圖磚。
- `docs/static-site-run.md` 增加本機預覽與自有靜態網站放置說明。

本執行環境的網路隔離禁止本機瀏覽器連線至啟動中的 `127.0.0.1` 伺服器；故無法在此完成 Chrome 實際地圖畫布驗收。修改已作靜態檢查及既有自動測試；使用者以 HTTP(S) 開啟 ZIP 解壓後網站時，應可正常載入同目錄資料。若以 HTTP 開啟後仍出現地圖錯誤，應再檢查 MapLibre CDN、OpenFreeMap 底圖連線及網站 CSP。

## 歐洲戰爭路線來源分拆

資料稽核發現大北方戰爭與奧地利王位繼承戰爭原先共用西班牙王位繼承戰爭來源。現已分別改連拉脫維亞國家歷史博物館的大北方戰爭專題及英國國家陸軍博物館的奧地利王位繼承戰爭條目；兩條路線仍明確標示為概略示意，不將來源文章冒充 GIS 航跡。自動化資料檢查確認各 Feature 的 source_id 對應正確且已登錄來源，10 項測試全數通過。
