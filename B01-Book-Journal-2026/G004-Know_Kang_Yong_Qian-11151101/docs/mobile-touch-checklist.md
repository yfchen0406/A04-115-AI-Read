# 手機與平板地圖觸控驗收清單

這份清單供網站放到自己的 HTTP／HTTPS 網址後，以實際 iPhone、Android 手機或平板檢查。瀏覽器視窗模擬不能代替實體觸控測試。

## 測試前

- 記下裝置型號、作業系統版本、瀏覽器名稱與版本，以及開啟網站的網址路徑（可省略私人網域）。
- 開啟「歷史地圖」區段，等待底圖、標記與控制列載入。
- 分別在「世界政權」、「全球貿易航線」、「戰爭與軍事路線」模式操作。

## 操作項目

1. 在地圖上單指向上／下滑動：頁面應可正常捲動，地圖不應搶走一般頁面捲動手勢。
2. 在地圖上雙指拖曳：地圖應平移，頁面不應跟著移動。
3. 雙指向外／向內捏合：地圖應放大／縮小；地圖標記與底圖保持對齊。
4. 輕點歷史事件或貿易港口標記：應出現詳情卡；詳情可閱讀，來源連結可開啟。
5. 操作年份、模式、國家選單與重設視角按鈕：控制項可點按，地圖仍與共用年份同步。
6. 開啟左右雙地圖：手機版應上下排列；兩張圖可各自平移縮放，年份保持同步。
7. 使用全螢幕後退出：畫布尺寸應恢復正常，地圖控制項仍可操作。
