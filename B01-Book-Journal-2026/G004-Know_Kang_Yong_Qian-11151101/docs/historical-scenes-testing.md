## 本機畫面驗收限制

本工作環境啟動本機 HTTP 伺服器後，環境的本機通訊端政策仍拒絕 `127.0.0.1` 瀏覽器請求（`ERR_CONNECTION_TIMED_OUT`／通訊端存取拒絕），因此未能在此瀏覽器實際看到場景、點選機械零件或觸控長卷。已停止測試伺服器。請解壓第五階段 ZIP，使用根目錄 `start-local-site.cmd` 啟動自己的本機 HTTP 預覽後驗收。

## 使用者端驗收步驟

1. 執行 `start-local-site.cmd`，確認第五階段導覽可跳至場景面板，並出現預設康熙場景。
2. 逐一切換康熙、雍正、乾隆、清代古畫、工業革命、廣州貿易、戰役、文化科技分類；檢查分鏡控制與史料連結。
3. 選紐科門及瓦特場景，按播放／暫停／重播及四種速度；點選 SVG 零件（或鍵盤 Tab 後 Enter），確認解說變更。核對紐科門場景沒有瓦特獨立冷凝器或飛輪，瓦特1765模型使用分離冷凝器與往復搖樑輸出。
4. 檢查《康熙南巡圖》與《乾隆南巡圖》原畫；可左右拖動／橫滑、觸控探索及縮放。若原畫服務未回應，確認本地 AI 手繪情境重建自動顯示。
5. 拖動第三階段年份，確認目前年份狀態即時更新；在場景外年份使用「前往場景年份」才同步年份。
6. 在廣州場景連動地圖，確認圖層切到貿易且共用年份不變；在戰役場景連動地圖，確認圖層及事件／路線定位。
7. 切換動畫效果關閉或系統降低動態，確認自動播放與視差停止而內文、熱點與控制仍可用；重新啟用動畫後仍留在目前捲動位置。
8. 以 390px、768px 及桌面寬度檢查版面、按鈕及長卷橫向操作；最後回歸檢查測驗、年表搜尋篩選、六項圖表與地圖資料。

尚未於實體 iPhone、Android 手機或平板操作；窄螢幕使用者端驗收仍待使用者在本機完成。
