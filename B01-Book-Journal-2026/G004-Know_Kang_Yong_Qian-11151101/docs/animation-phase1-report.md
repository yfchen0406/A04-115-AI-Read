# 第一階段動畫改版紀錄

## 專案盤點

- 單頁網站：`index.html`；另有 `economic_data.json`、原封面 `images/qing-cover.png`，以及本階段新增的四張 WebP 示意插畫。
- 原頁面包含 11 個章節：序章、歷史時間軸、康熙、雍正、乾隆、經濟資料庫、中西世界對照、三帝比較、歷史啟示、知識測驗、資料來源。
- CSS 與核心知識測驗、歷史事件時間軸、閱讀進度程式內嵌於 HTML；世界年表互動與經濟圖表各有獨立內嵌腳本。
- 原頁面已有 IntersectionObserver `.reveal`、事件卡展開、事件篩選、世界年表播放／搜尋、六項經濟指標圖表及測驗判分。
- 專案目錄沒有 Git 版本庫。修改前備份位於 `backup-phase1-before-20261031-203111/`，含原 HTML、JSON 與 images。

## 新增與修改

- `css/qing-animations.css`：卷軸邊框、雲紋、朱印、金線、插畫框線、手機版樣式及關閉動畫時的即時呈現。
- `js/qing-animations.js`：GSAP／ScrollTrigger 章節、首頁、時間軸、圖表、卡片動畫；動畫銷毀與重建；localStorage 與系統減少動態偏好。
- `index.html`：僅加入 CSS／JS 載入與動畫開關控制。
- 原始 `economic_data.json` 及圖片保持不變；原有互動程式未改寫。

## 動畫項目

- 首頁卷軸揭幕約 2.2 秒，封面影像緩慢放大並淡入，標題內容淡入，朱印顯現，雲紋低對比裝飾，背景隨捲動微幅視差。
- 三帝章節採各自進場：康熙卡片由右向左揭卷、雍正卡片由上展開、乾隆卡片以微幅山水式淡入；康熙採卷軸邊飾、雍正強化奏摺朱紅框線、乾隆加入金色收束線。新增康熙、雍正、乾隆 AI 示意肖像及乾隆山水長卷；原封面保留不變，插畫均標註「AI 生成歷史意象插畫，非史料原件」。肖像延遲載入並淡入，山水圖使用輕微捲動視差。
- 全站章節標題、內文卡片及比較卡片柔和進場；桌面比較卡左右交錯，手機改為垂直淡入。
- 歷史軸線隨捲動延伸，事件依序顯現；年份由 1600 遞增至事件年份並在選取時強調。事件詳情以 CSS 平滑展開；使用 MutationObserver 處理篩選後重建的事件卡。
- 經濟與中西比較區塊淡入，圖表原本的年份播放、指標切換及資料繪製邏輯保持原樣。
- 動畫控制鈕設於導覽列並記錄偏好；關閉時立即顯示內容且保留閱讀位置。系統設定降低動態效果時停用 GSAP，控制鈕同步說明系統偏好。localStorage 受限時使用記憶體偏好作為本頁 fallback。

## 驗收與限制

- 已檢視頁面章節、主要互動 DOM、內嵌腳本及圖片／資料檔案，確認新增入口以獨立 CSS／JS 掛載。
- 已完成原有三段內嵌 JavaScript 與新增動畫模組的語法檢查、HTML 模組路徑與 11 章節數量核對、無重複 ID 與頁內錨點完整檢查、economic_data.json 逐字一致檢查、封面圖片雜湊一致檢查，以及 ZIP 必要檔案清單檢查。另以備份比對原始 index.html，在移除新增 CSS／JS 載入與動畫按鈕後可逐字還原。
- 瀏覽器互動驗收仍未完成：本機檔案網址被瀏覽器安全政策拒絕；依政策停止嘗試以其他瀏覽器途徑重現同一頁面。因此尚未觀察 Chrome console、事件播放、圖表切換、測驗作答、動畫開關實際畫面與行動版排版。需使用者在本機以既有預覽方式開啟後完成這些人工項目。
- GSAP 3.12.5 與 ScrollTrigger 由 jsDelivr CDN 載入。離線或 CDN 無法連線時，原站功能仍可使用，但新增 GSAP 動畫不會啟動；CSS 裝飾仍存在。
- 原始 `.reveal` 使用 IntersectionObserver，屬現有行為；動畫關閉樣式會覆蓋其隱藏狀態，確保內容可讀。

## Netlify 部署

將此資料夾根目錄作為靜態發布目錄；需連同 `index.html`、`economic_data.json`、`images/`、`css/` 與 `js/` 一起部署。此版本不需要建置指令。若要離線提供 GSAP，需另將 GSAP 與 ScrollTrigger 檔案放在站內並將 HTML CDN 位址改為相對路徑。
