# 第五階段交付報告｜歷史場景、清代長卷與機械互動

## 本階段內容

- 新增 29 個資料驅動場景及分類篩選：康熙、雍正、乾隆宮廷；兩幅清代南巡圖長卷；五種蒸汽／紡織機械；廣州貿易；清朝、歐洲、美洲戰事；文化科技比較。
- 依使用者回饋調整場景排版：本幕解說置於場景主視覺上方，所有場景選項改為可換行的橫向按鈕列，桌機與手機均不以橫向滑桿瀏覽場景清單。
- 新增獨立場景引擎，支援場景載入／卸載、分鏡、播放／暫停／重播、0.5／1／1.5／2 倍速、鍵盤操作、原畫長卷觸控滑動與滑鼠拖曳、縮放及全螢幕。
- 場景讀取第三階段 `HistoricalTimeController` 目前年份；超出場景年代時仍保留文字內容並顯示年代提示。選取「前往場景年份」才更動共享年份。
- 透過第四階段 `HistoricalMap.setMode()` 及新增 `HistoricalMap.focusFeature()`，將場景切換到貿易、軍事、清朝或歐洲圖層並聚焦相關事件／路線。廣州貿易場景保留當前年份；其他場景連動至目前分鏡年份。
- 皇帝宮廷、戰事、港口、機械及制度流程均為自製 CSS/SVG「歷史情境重建」或「技術示意」，不冒充照片或原件。機械 SVG 的主要部件可點選／鍵盤聚焦查看用途。
- 康熙與乾隆南巡圖使用大都會藝術博物館標示為 Public Domain 的原畫數位影像，並顯示作者、年代、收藏機構、物件頁及權利註記。原畫影像服務需網路；失敗時自動顯示本地示意長卷。
- 清準、大小和卓、大小金川、七年戰爭、美國獨立戰爭與法國大革命戰爭以階段文字呈現；概略線路只在連動地圖上按原有資料顯示，並清楚註明不等於精確行軍路徑。第一次及第二次金川戰事分開標示。
- 互動遵守全站「動畫效果」設定及 `prefers-reduced-motion`；降低動態模式下保留所有歷史文字與控制，停止自動播放、視差與 CSS 循環動畫。
- 已按場景內容生成 29 張 16:9 AI 手繪插畫並逐張檢視；一般場景直接呈現本地插畫，五種機械場景保留互動原理 SVG 並以插畫襯底，兩幅南巡圖以切換按鈕保留博物館原畫並另示情境重建。尺寸與檔名記錄見 `docs/historical-scenes-image-generation-log.md`；提示詞見 `docs/historical-scenes-image-prompt-inventory.md`。

## 本機開啟

將 ZIP 解壓至同一資料夾，執行根目錄 `start-local-site.cmd`，由瀏覽器開啟顯示的本機網址。場景 JSON、既有事件及地圖 GeoJSON 需要 HTTP；Met 原畫、地圖底圖及既有 CDN 函式庫需要網路。沒有部署、預覽網址或 GitHub 推送。

## 已知限制

- 本機示意場景與機械非精密比例模型或可直接用於工程教學的機械設計圖。
- 場景使用第三階段既有事件資料；目前年表未登錄的 1712、1766、1767、1784 等技術節點，只在第五階段來源說明與分鏡呈現，沒有修改原始歷史事件庫。
- MapLibre 底圖仍取決於網路/CDN/底圖服務。底圖失敗時，場景敘述、來源及年表仍可用。
- 尚未以實體 iPhone、Android 手機與平板驗收；目前以 Windows 本機桌面瀏覽器與窄視窗模擬檢查。
