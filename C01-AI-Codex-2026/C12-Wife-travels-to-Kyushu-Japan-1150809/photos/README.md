# 每日旅遊照片

每一天都有獨立的紀錄頁，請把照片放進相對應的資料夾，並依序使用 `01.webp`、`02.webp`、`03.webp` 等檔名。

- `photos/day-1/`：鹿兒島、霧島、天文館
- `photos/day-2/`：指宿、長崎鼻、仙巖園
- `photos/day-3/`：櫻島、關之尾瀑布、青島
- `photos/day-4/`：日向岬、高千穗、阿蘇
- `photos/day-5/`：菊池溪谷、柳川、鳥栖、福岡

每一頁已先保留 6 個照片位置。放入圖片並重新整理該日頁面後，就會自動顯示；網站會依序辨識 WebP、JPG、JPEG、PNG，建議優先使用 WebP。
