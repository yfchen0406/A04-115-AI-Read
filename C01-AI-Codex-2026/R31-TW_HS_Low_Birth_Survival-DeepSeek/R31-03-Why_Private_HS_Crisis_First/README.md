# 台灣高中少子化生存戰｜第3集：私校經營篇

雙擊 `index.html` 開啟首頁，選「開始閱讀」進入播放器。頁面、圖片、音訊和字幕採相對路徑；兩個 YouTube 替代網址只在 `index.html` 的「單一連結設定區」。首頁會明確提示正式影片網址待補，按鈕目前暫連 YouTube 首頁。

## 素材狀態

- 本站依 `data/timeline.json` 的 Excel 毫秒時碼同步 43 鏡、15 章節、184 個 SRT 字幕 cue。
- `images/cover.webp` 使用提供的 `R031-03-cover.webp` 正式封面。
- `images/001.webp` 至 `images/043.webp` 依鏡號對應根目錄 `webp_images/V03-001.webp` 至 `V03-043.webp` 的正式圖片。
- 網站字幕版在不改原意下將「温順德」校正為「溫順德」，並將「设备」校正為「設備」；原始 SRT 未更動。
- 原始 MP3 保留不動；播放器使用同一旁白轉製的 96 kbps CBR、24 kHz 單聲道 MP3，以利瀏覽器穩定跳轉。播放速度維持 1.0。原始音訊 971.220 秒，播放副本 971.280 秒；Excel 末點差異依播放副本記錄為 0 毫秒。
- 章節索引跳轉已修正：需收到 `seeked`、音訊資料可播放並經兩個畫格確認定位穩定後才恢復播放；若位置未穩定會重試一次。使用者回報的首字截斷仍待逐章實際聽辨確認。

Remotion 可檢視來源與建置素材副本位於 `remotion-source/`。完整時間軸 JSON 位於 `data/timeline.json`。
