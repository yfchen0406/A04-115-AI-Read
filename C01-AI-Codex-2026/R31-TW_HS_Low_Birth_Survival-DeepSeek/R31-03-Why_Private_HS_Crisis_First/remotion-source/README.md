# A03 Remotion 專案來源

`src/Timeline.jsx` 以 Remotion Composition 讀取 `public/data/timeline.json`，由 MP3 播放時鐘呈現 Excel 鏡頭區間、章節、字幕與圖片。`public/` 是自包含素材副本。

安裝 Node.js 後，在此資料夾執行 `npm install`，再執行 `npm run studio` 可開啟 Remotion Studio；`npm run render` 可輸出影片。這是可檢視與建置的 Remotion 組成來源，離線網站本身使用隨 ZIP 提供的 Remotion Player 瀏覽器包。

正式封面 `R031-03-cover.webp` 已放入 `public/images/cover.webp`。根目錄 `webp_images/V03-001.webp`–`V03-043.webp` 依鏡號置入 `public/images/001.webp`–`043.webp`。
