# The SMALL BIG｜原則閱讀手帳

依據提供的「幸福檔案」參考網站架構製作：書籍封面、閱讀引言、分類索引、搜尋、分頁卡片與逐則細讀視窗。

## 插圖

共 53 張：封面 P00.webp，以及 52 個原則 P01.webp–P52.webp。插圖提示詞在 [illustration-prompts.md](illustration-prompts.md)。目前網頁先預留圖槽，待插圖依檔名放進 images 資料夾便會顯示。

人物參考照片使用專案根目錄的 B01-wife.png，提示詞將人物安排為配角。

開啟 index.html 即可使用本機網站。搜尋、五類分類、分頁、隨機抽選和細讀視窗皆不需要外部套件。

逐張圖片的檔名、標題、比例與生成狀態見 [images-manifest.csv](images-manifest.csv)。

圖片框目前留白；圖片放入 images 資料夾時使用 WebP 檔名 P00.webp–P52.webp。提示詞與位址清單壓縮檔：[The-SMALL-BIG_插圖提示詞與檔名清單.zip](The-SMALL-BIG_插圖提示詞與檔名清單.zip)。
