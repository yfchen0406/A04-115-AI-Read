# A259《開車心理學》動態閱讀網頁

## 使用方式

直接開啟 `index.html`，按下「播放」即可離線播放。

本專案使用 78 張 WebP 插畫、Edge TTS 台灣中文男聲與實際音訊句界。播放時字幕固定在畫面下方；控制列播放後隱藏，移入畫面或暫停時重新顯示。

## 音訊

- 聲音：Microsoft Edge TTS `zh-TW-YunJheNeural`
- 語速：-4%
- 實際長度：475.392 秒
- MP3：`audio/narration-zhTW-YunJheNeural-v2.mp3`
- 本機備份 WAV：`audio/narration-zhTW-Zhiwei-local.wav`

## 同步資料

- `captions.json`：78 段字幕句界
- `captions.srt`：78 段 SRT 字幕
- `timeline.json`：78 張圖片、運鏡與實際時間軸

原始 PNG 與 16:9 正規化 PNG 分別保存在 `source/png` 與 `source/png-16x9`，未覆寫原始參考圖與劇本。
