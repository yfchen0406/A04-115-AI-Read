# A08 自然旁白 12 分鐘響應式動態閱讀版

本版本從 `A08-reading-web-natural-12min-v2` 複製建立，原 v2 完全保留不修改。

- 144 個連續畫面單位；依實際旁白 612.557 秒平均配置，每張約 4.254 秒。
- 使用 234 張完整版圖片中的代表畫面，圖片以獨立檔名放入本專案。
- 同一段落固定運鏡方向，圖片以雙圖淡入淡出連續銜接。
- 字幕固定在畫面下方，時間已依實際旁白 SRT 校正。
- 已接入 `audio/narration-zhTW.mp3`，使用 `zh-TW-YunJheNeural`，語速設定為 -30%。
- 播放時由音檔 `currentTime` 驅動圖片、字幕與進度列，避免瀏覽器計時器與聲音逐漸失步。
- 圖片已依實際旁白字幕重新從 234 張原始插畫挑選；開場、各排名與結語只在對應旁白開始時切換。
- `visual-match-report.md` 可逐格查看字幕、原始圖片名稱與選圖主題。
- 左上角段落標題在該段播放期間持續顯示，直到下一個段落開始才更新。
- 響應式版面支援桌機、平板、手機直立與手機橫放；手機改用大觸控按鈕與避開字幕的控制列。
