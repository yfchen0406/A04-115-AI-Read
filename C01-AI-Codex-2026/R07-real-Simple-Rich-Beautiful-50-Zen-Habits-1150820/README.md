# 簡單豐盛美好－動態閱讀網頁 v2

本版本保留原旁白、字幕、章節與分鏡資料，重新生成 61 張約每 5 秒切換的 Q 版手繪插畫。每張圖以 `yfchen.png` 為唯一人物基礎，使用正常一雙手，排除其他人物、重複手臂與多餘肢體。

## 使用方式

直接開啟 `index.html`，先在封面按「開始閱讀」，再播放 Microsoft Edge `zh-TW-YunJheNeural` 男聲旁白。

## 檔案說明

- `assets/covers/cover.webp`：Q 版手繪封面。
- `assets/images/visual-001.webp` 至 `visual-061.webp`：約每 5 秒切換的圖片。
- `audio/scene-01.mp3` 至 `scene-08.mp3`：可替換的男聲旁白檔案。
- `web-upload-package/`：可直接上傳的完整靜態網站包。
